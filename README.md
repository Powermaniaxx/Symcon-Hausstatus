# Hausstatus – Rückkehrstand 0.26.2

Dieser Zweig stellt die gemeinsame Übersicht aus 0.26 wieder her. Er ergänzt die Wiederherstellung der Sichtbarkeit nach der Einzelkachel-Aufteilung und liest die dauerhaft gespeicherten Rückkehrdaten aus 0.29.

In Module Control beim Hausstatus-Zahnrad **rollback-0.26** wählen, danach in der zentralen Hausstatus-Instanz **Änderungen übernehmen** und die Visualisierung neu laden. Zur aktuellen Version denselben Zweigschalter auf **main** stellen.

Quellen und Instanzen bleiben erhalten. Die Einzelkacheln werden ausgeblendet; die gemeinsame Instanz und die auf sie zeigenden Links werden wieder sichtbar. Geräteaktionen und Automationsskripte werden beim Rückwechsel nicht ausgeführt.
